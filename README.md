# 狼人杀 H5 · AI 主持人版

移动端 H5 狼人杀：**多真人联机 + AI 补位 + AI 主持人语音播报**。

- 6 人局：2 狼人 · 2 村民 · 预言家 · 女巫（屠边规则）
- 创建房间 → 朋友打开链接输入房间号即入座，**空位由 AI 补齐**
- AI 主持人全程控场：**天黑闭眼 → 狼人睁眼商量刀谁 → 预言家睁眼验人 → 女巫睁眼（问解药、再问毒药） → 天亮公布死讯 → 组织发言 → 投票 → 播报「游戏继续 / 游戏结束」**
- AI 玩家会按身份说话（狼人伪装、预言家报查验、会接着上一个人的话反驳）、自主决策、有倾向地投票；发言以气泡显示并实时朗读
- 夜里死亡和被投票放逐的人都要留**遗言**（AI 自动生成，真人自己说）
- 夜晚狼队商议刀口（AI 队友会提名给理由，你可以改刀）
- 发言支持**按住说话**（语音识别转文字）或打字
- WebRTC 网状**实时连麦**（点「连麦」开启，轮到谁发言谁开麦）
- 出局自动转观战；结算翻牌亮出全部身份 + 本局大事记；房主可一键再来一局
- 断线重连不丢座位、不丢进度

## 快速开始

```bash
npm install
npm start          # 默认 http://localhost:3000
```

同一 WiFi 下的朋友用手机浏览器打开 `http://<电脑IP>:3000` 即可一起玩。
正式联机请部署到 HTTPS 环境（麦克风权限要求），并设置 `PORT` 环境变量。

## 可选：接入大模型，让 AI 说话更像真人

不配也能玩（内置话术引擎）。配上下面三个环境变量后，AI 发言与遗言自动改成大模型生成，失败会静默回退到话术引擎：

```bash
LLM_BASE_URL=https://api.deepseek.com/v1   # 任何 OpenAI 兼容地址
LLM_API_KEY=sk-xxxx
LLM_MODEL=deepseek-chat
npm start
```

## 技术架构

```
public/          H5 客户端（原生 JS，无构建）
  app.js           WebSocket 状态同步 + 界面渲染
  voice.js         WebRTC 网状连麦（服务端只转发信令）
server/
  index.js         HTTP + WebSocket 服务、房间路由、断线重连
  game.js          权威游戏状态机（夜晚/白天/投票/结算），身份只存服务端
  ai.js            AI 玩家的发言、遗言、刀人、查验、用药、投票决策
  llm.js           可选的大模型接入层（OpenAI 兼容，未配置则不启用）
tests/e2e.mjs     Playwright 双真人 + AI 全流程回归
tests/sim.mjs     不开浏览器，几秒跑完一整局，验证播报顺序/发言/遗言/胜负
```

协议：JSON over WebSocket。客户端收到的是**按人过滤后的状态**（别人的身份不下发），作弊面为零。

## 测试

```bash
npm run sim                 # 纯服务端快跑一整局（GAME_PACE=0.08 压缩节奏）
npm start &                 # 起服务
node tests/e2e.mjs          # 两个无头浏览器真人 + 4 个 AI 打完整局
```

覆盖：建房/加入 → 准备开局 → 夜晚行动 → 轮流发言 → 投票放逐 → 遗言 → 结算翻牌 → 再来一局。

调试节奏：`GAME_PACE` 控制所有停顿的倍率，`GAME_PACE=1` 为真实节奏，压测时可设 0.1 ~ 0.4。
